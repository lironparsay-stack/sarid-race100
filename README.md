# המירוץ ל-100 · אתר הסרטונים

אתר סטטי (בלי שרת) לצפייה בכל סרטוני המירוץ ל-100 של קיבוץ שריד.
פותחים את `index.html` בדפדפן, ישירות מהמחשב או מאתר מתארח (GitHub Pages).

## מבנה התיקייה

| קובץ / תיקייה | מה זה |
|---|---|
| `index.html` | הדף עצמו |
| `assets/site.css`, `assets/app.js` | העיצוב וההתנהגות של הדף |
| `assets/logo.webp` | הלוגו |
| `assets/hero.jpg` | תמונת הרקע הגדולה (לא חובה, ראו בהמשך) |
| `assets/thumbs/NN.jpg` | תמונה ממוזערת לכל סרטון (`01.jpg` עד `16.jpg`) |
| `race100-videos.xlsx` | **רשימת הסרטונים. את הקובץ הזה עורכים.** |
| `data/pairs.json` | רשימת הזוגות (שם צוות, חברים, מזהה סרטון ביוטיוב) |
| `data.js` | נוצר אוטומטית מהאקסל ומ-`pairs.json`. לא עורכים ידנית |
| `scripts/` | הסקריפטים שמייצרים את `data.js` ומורידים תמונות ממוזערות |

## התקנה (פעם אחת)

צריך [Node.js](https://nodejs.org) בגרסה 18 ומעלה. בתיקיית הפרויקט מריצים:

```
npm install
```

## עדכון האתר

1. עורכים את `race100-videos.xlsx` (או את `data/pairs.json`) ושומרים.
2. מריצים:

```
npm run update
```

זה הכל. הפקודה מורידה תמונות ממוזערות חסרות מ-Google Drive, ואז כותבת מחדש את `data.js`. מרעננים את הדף בדפדפן ורואים את השינויים.

פקודות נפרדות, אם צריך:
- `npm run build` כותב רק את `data.js` (בלי להוריד תמונות)
- `npm run thumbs` מוריד רק תמונות ממוזערות

### מה צריך לדעת על האקסל
- **קישור דרייב:** מדביקים את קישור השיתוף (`https://drive.google.com/file/d/.../view`). הסקריפט מחלץ ממנו את המזהה בעצמו. סרטון בלי קישור מוצג ככרטיס מעומעם עם תג "בקרוב" ולא ניתן ללחוץ עליו.
- **שיתוף:** כל סרטון בדרייב חייב להיות משותף כ"כל מי שיש לו את הקישור – צפייה", אחרת הנגן והתמונה הממוזערת לא ייטענו.
- **משך ותיאור:** לא חובה. משך (`03:16`) מוצג כתג על התמונה, ותיאור מוצג בנגן.
- **חלק:** `חלק א'` או `חלק ב'` קובעים את הטאב.
- **אודישנים:** כדי להוסיף סרטון אודישן, מוסיפים שורה חדשה עם מספר, כותרת, ובעמודת "חלק" כותבים `אודישנים`. הסרטון יופיע בטאב "האודישנים" (כל עוד אין שם סרטונים מוצגת ההודעה "הסרטונים יעלו בקרוב").

### תמונות ממוזערות
- הסקריפט מוריד תמונה רק לסרטון שיש לו קישור דרייב **ושאין לו עדיין** `assets/thumbs/NN.jpg`.
- רוצים פריים אחר? שמים קובץ משלכם בשם `assets/thumbs/05.jpg` (למשל) ומריצים `npm run update`. קובץ שקיים **לעולם לא נדרס**.
- כדי להוריד מחדש תמונה מדרייב, מוחקים את הקובץ ומריצים שוב.
- סרטון בלי תמונה מקבל תמונת placeholder עם הלוגו. לזוגות משמשת התמונה של יוטיוב אוטומטית.

### תמונת הרקע (Hero)
שומרים תמונה רחבה בשם `assets/hero.jpg` ומריצים `npm run update`. בלי תמונה כזו האתר משתמש בתמונה הממוזערת הראשונה שקיימת, ואם אין, ברקע גרדיאנט.

### טקסטים
התיאור בראש הדף והקרדיטים בתחתית נמצאים ישירות ב-`index.html` (מחפשים "לכבוד מאה שנה" או "הפקה:").

## פרסום ב-GitHub Pages

1. יוצרים ריפו חדש ב-GitHub ומעלים אליו את כל תוכן התיקייה (חוץ מ-`node_modules`, שכבר מוחרגת ב-`.gitignore`).
2. בריפו: **Settings ← Pages ← Build and deployment**, בוחרים **Deploy from a branch**, ענף `main` ותיקייה `/ (root)`, ושומרים.
3. אחרי דקה-שתיים האתר זמין בכתובת `https://<שם-המשתמש>.github.io/<שם-הריפו>/`.
4. כל עדכון: מריצים `npm run update`, ואז מעלים (commit + push) את הקבצים שהשתנו (בדרך כלל `data.js`, האקסל ותמונות ב-`assets/thumbs`).

הערות:
- הקובץ `.nojekyll` נדרש כדי ש-GitHub Pages יגיש את הקבצים כמו שהם. לא למחוק.
- כל הנתיבים באתר יחסיים, כך שהוא עובד גם מתת-תיקייה.
- קובץ האקסל, הגיבויים והמפרט **לא** עולים לריפו (מוחרגים ב-`.gitignore`). רק `data.js` שנוצר מהם עולה.
- כרגע הדף מסומן `noindex` (מנועי חיפוש לא יציגו אותו). כשמשיקים, מוחקים את השורה `<meta name="robots" ...>` ב-`index.html`.

## בדיקה מקומית
פשוט פותחים את `index.html` בדפדפן (לחיצה כפולה). הערה: סרטוני יוטיוב (טאב הזוגות) לפעמים מסרבים להתנגן בדף שנפתח ישירות מהדיסק. באתר המפורסם הם עובדים, ובכל מקרה יש בנגן קישור "פתיחה ב-YouTube".
